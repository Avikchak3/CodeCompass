# 🧭 CodeCompass

> AI-Powered Developer Onboarding Tool

CodeCompass helps software developers (freshers or experienced) understand any codebase instantly. Upload your project files and get an AI-generated onboarding guide.

## ✨ Features

- 📍 **Step-by-step Roadmap** — Know exactly where to start
- 📂 **Key Files Highlighted** — Most important files explained
- 🔀 **Architecture Diagram** — Visual flow of the project
- 🧱 **Tech Stack Detection** — Auto detects all technologies
- 💬 **AI Chat** — Ask anything about the codebase

## 🛠️ Tech Stack

- **Frontend** — React.js
- **Backend** — Node.js + Express
- **AI** — Groq API (LLaMA 3.3 70B)
- **Diagrams** — Mermaid.js

## 🚀 Getting Started

### Backend
```bash
cd backend
npm install
node server.js
```

### Frontend
```bash
cd frontend
npm install
npm start
```
